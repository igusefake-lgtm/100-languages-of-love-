100 LANGUAGES OF LOVE — SUNFLOWER WEBSITE

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser to preview.
3. Upload the files to a GitHub repository and enable GitHub Pages to publish it.

The page is mobile-friendly and contains a sunflower with 100 petals. Use the arrows or
“Reveal the next petal” to move through the love phrases. It uses Google Fonts when online;
system fallbacks are provided.

Note: translations and romanizations can vary by region and context.
